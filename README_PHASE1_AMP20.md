# GuitarDSP-Pro Phase 1 — Amp20

This build keeps the Phase 0 shell and inserts an experimental 20-stage amplifier engine.

## Goal

- Keep every internal amp stage editable.
- Increase stage count only where a stage has an understandable electrical/acoustic role.
- Avoid making every stage "another Drive knob".
- Keep newly-added stages near-neutral by default so the old 12-stage sound is not destroyed merely by increasing the stage count.

Read `docs/AMP20_MANUAL.md` before tuning the amp.
